SEARCH UPDATE

Digital Library search now supports:
- Product Description
- Alternate / old descriptions
- Maker
- Part Number
- Job Number
- Current rating
- Voltage rating
- Price

Primary use case:
Search a product and see every Job Number where it was used.
Search a Job Number and see all products associated with that job.

Job history is combined from:
- Imported old Excel BOM history
- Quotes
- BOMs
- Ordering records

Click a Part Number to open Product History.
Click a Job Number to filter the library to that job.

Use the same shop-data.json if replacing an existing installation.
